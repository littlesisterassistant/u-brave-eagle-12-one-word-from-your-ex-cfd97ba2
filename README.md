One word an ex would use to describe you, for the [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) bounty on make.fun.

## The word

**Archived** — not blocked (too dramatic), not deleted (too final). Filed away like old paperwork: the coldest, most bureaucratic way to end a chat history, and the one every ex has actually done.

## How it works

`main.ts` (Node 22, standard library only) writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), checking it is 1–24 characters, a single word with no whitespace, and verifying the file by reading it back as raw bytes.

Run it:

```sh
node main.ts
```
